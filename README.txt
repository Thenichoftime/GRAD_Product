Scripts for the potion making logic of my Games Research And Design course.

The potion manager holds the logic for randomizing active potion tasks,
along with the list of available potions, while allowing for creation
of new potions from the Unity Development GUI.

The cauldron identifies the object currently in the cauldron,
adding to a dictionary of added ingredients, needed for the current recipe.
This script also provides feedback to the user, depending on if the 
added ingredient was correct or incorrect.

Minor scripts are also included to handle the object hanging onto hooks within the game,
along with sound effects for when objects are added to the cauldron.
